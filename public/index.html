Every session has a home.

Quản lý phiên trên máy cá nhân và máy chủ SSH.

Đăng nhập

Chưa có mật khẩu. Mở terminal trên máy chủ và chạy:

cd termnest && npm run set-password

Xong rồi tải lại trang này.

Tắt máy vẫn chạy. Chỉ dừng khi máy chủ tắt.
