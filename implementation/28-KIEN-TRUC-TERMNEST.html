01 · Vì sao cần

Chạy nhiều agent, mệt nhất là phải để mắt tới chúng

Agent viết code rất nhanh. Thứ tốn thời gian là đi tìm xem phiên nào đang chờ mình, mở lại những phiên bị mất, và đoán agent đã làm tới đâu.

🔍

Phải mở từng cửa sổ SSH

14 phiên trên 3 máy = 14 cửa sổ. Phiên hỏi "y/n" lúc 2 giờ chiều, tới 5 giờ mới thấy.

⚡

Server khởi động lại là mất hết phiên

Cập nhật đêm làm server bật lại: các phiên biến mất, phải nhớ phiên nào chạy chat nào để resume tay.

📊

Không rõ mỗi tài khoản còn bao nhiêu quota

Nhiều tài khoản Claude/Codex, không rõ tài khoản nào sắp hết, hôm nay tốn bao nhiêu.

📄

Muốn xem kết quả phải tải về

Agent viết tài liệu, báo cáo HTML trên server; muốn đọc thì phải chép về máy.

💻

Đổi máy là phải cài lại từ đầu

Thêm lại từng server, mật khẩu, cài đặt; chat của các phiên trên máy cũ ở lại máy cũ.

🌙

Đi ra ngoài là mất dấu

Rời bàn làm việc thì không biết agent vẫn đang chạy hay đang đợi mình trả lời.

07 · Chuyển phiên · đổi máy MỚI

Chat đi theo bạn, dù mỗi máy để code một chỗ

TERMNEST tìm đúng repo ở máy đích theo git origin, đặt chat vào đó, đổi đường dẫn cũ sang mới rồi mở lại. Chỉ cho phép khi cùng một tài khoản Claude/Codex. Hồ sơ Claude ở máy đích được tìm cả trong ~/.claude* và ~/.config/claude*; hồ sơ mặc định chưa đăng nhập thì tự chọn hồ sơ cùng tài khoản. Tệp liên quan đi cùng: tệp agent đã tạo/sửa, tệp nhắc trong chat, ảnh/CSS/JS của trang HTML — chỉ chép tệp máy đích thiếu hoặc khác, bản khác ở đích được giữ thành .truoc-chuyen-<giờ>.

08 · Tính năng

TERMNEST làm được những gì

🖥

Phiên và terminal

  • Tạo phiên shell / Claude / Codex
  • Tab "Tất cả": lưới mọi phiên xếp theo chờ bạn → đang chạy → đang nghỉ, trả lời nhanh
  • Chia màn hình, toàn màn hình, lệnh mẫu
🔔

Theo dõi

  • Đang chạy · chờ bạn · xong theo trạng thái Claude / Codex tự ghi
  • Trạm Ops ở đầu tab Vận hành: tìm tiến độ, báo cáo Ops, hỏi sâu (mục 11)
  • Tự trông crew 24/7 (mục 10)
  • CPU, RAM, ổ đĩa, dịch vụ lỗi
  • Ngữ cảnh còn lại, gợi ý handoff
♻️

Khôi phục và di chuyển

  • Mở lại phiên và chat sau khi máy bật lại
  • Chuyển phiên sang server khác, mang theo tệp liên quan
  • Đổi máy bằng một tệp
📁

Tệp

  • Duyệt, tìm, xem Markdown / HTML / ảnh
  • Bấm tên file trong terminal là mở ngay: chỉ mục tên tài liệu lập sẵn khi mở phiên
  • Gửi file vào phiên, lấy từ server khác
  • Thùng rác, file tạm, tự dọn
📊

Token AI

  • Nhiều tài khoản Claude / Codex
  • Hạn mức tuần (và 5 giờ khi gói có); token và chi phí
  • Biểu đồ theo ngày, model, phiên
🐱

Thân thiện

  • Mỗi phiên một bạn thú, sân chơi, cây búa
  • Ghi chú, nhắc việc
  • Hiệu ứng, chế độ gọn, tiếng Việt / English

Nhiều team crew trên nhiều máy chạy liên tục, không ai phải canh
